Renders a single Lucide glyph; use it anywhere the design needs an icon instead of hand-writing SVG.

```jsx
<Icon name="book-open" size={20} />
```

Requires `<script src="https://unpkg.com/lucide@0.454.0/dist/umd/lucide.js"></script>` on the page. Icons are stroke-only, 1.75px, never filled, never coloured except via `color` or inherited `currentColor`.
